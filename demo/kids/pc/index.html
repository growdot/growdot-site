今天想先做哪一件？

把作业排成一条小火车路线再出发，读一点书，闯一关。
每天一点点，积累看得见。

🐥
🌱 从你家现在最困扰的一件事开始

不是让孩子学得更多，
而是把本来就要做的事，变得更有条理。

家长少一点反复催促，孩子更清楚今天要做什么；学过但没掌握的内容可以回来练；每天一点点阅读，也能慢慢积累成看得见的成长。
家长负责规划把固定要做的事情提前安排好，不必每天重新布置。
孩子负责今天每天只需要知道：今天做什么、练什么、读什么。
系统负责把积累串起来做过的有记录，不会的能回来，长期积累也能看得见。

你家现在最想解决哪个问题？

不用一次学会所有功能。先从一个真实问题开始。

✓
每日成长
每天的学习总要催？

把“家长天天提醒”变成“孩子自己看今天”。

如果你家也有这些情况：
写作业拖延，不知道先做什么
固定任务很多，家长每天都要重复提醒
计划定了不少，但经常三天后就停了
想培养孩子自己安排、自己完成的习惯
提前安排 → 每天自动出现 → 孩子完成 → 获得积分 → 兑换奖励

把每天、每周固定要做的事情提前设好，之后孩子打开工作台，就能直接看到今天要做什么。

🎯
趣味闯关
学过了，过几天又忘了？

把真正需要记住的内容，多遇见几次。

如果你家也有这些情况：
错题散落在作业本、练习册和试卷里
错题订正过，过几天还是会错
古诗会背，但容易漏字、串句、写错字
生字、单词、刚学过的知识总是记不牢
真正容易错、容易忘的内容 → 换一种方式再遇见 → 多练几次 → 逐渐掌握
错题换一道类似题再练
古诗补句 · 排序 · 易错字
单词选择 · 拼写 · 辨认

不是为了刷更多题，而是通过答题、闯关和即时反馈，让真正需要记住的内容多遇见几次。

📚
阅读成长
阅读总是坚持不下来？

让每天一点点阅读，慢慢变成看得见的积累。

如果你家也有这些情况：
说好每天阅读，却经常三天打鱼两天晒网
今天读了多久、最近读过什么都记不清
一本书读了很多天，缺少持续推进的感觉
英语绘本一本本读，但长期积累不明显
选一本正在读的书 → 每天读一点 → 留下记录 → 山峰往前走一点

重点不只是“计了多少分钟”，而是让孩子慢慢看到：我坚持了多久、读完了什么、已经走了多远。

第一次使用，只做一件事就可以

不用把三个模块一次都配好。哪件事现在最困扰你，就先从哪件事开始。
